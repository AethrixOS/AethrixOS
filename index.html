A operating system, built from scratch.

Aethrix is a small kernel, a bootloader and a shell, written from first principles so every decision can be read and questioned. It is early, and it says so.

$ aethrix --about

Not a distribution. A foundation.

Most "new" operating systems are Linux with a different wallpaper. Aethrix is not that. The bootloader, memory manager and scheduler are original code, not a fork.

That also means it is small, rough, and only runs in a virtual machine for now.

$ aethrix --features

What actually works today.

Custom bootloader

Two-stage boot into protected mode.

Kernel

Monolithic core with a modular subsystem interface.

Memory manager

Paging and a physical frame allocator.

Filesystem

Journaled native filesystem, still early.

Terminal shell

A basic command prompt to poke around in.

Security as a constraint

Isolation goals shape the design. Not a finished feature.
